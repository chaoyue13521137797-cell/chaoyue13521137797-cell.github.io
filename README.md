# 福文化样本发现小样

这是一个参考 Calico `Entdecken` 页面制作的静态小样。当前先实现“发现”界面：白底全屏、顶部三入口导航、颜色/内容切换、可拖拽缩放的碎片地图、右侧个人收藏、底部分类入口和年份时间轴，以及点击样本后的展示页面。

## 打开方式

当前工作区可用本地服务预览：

```text
http://localhost:8766/fu-culture-tsne-map/
```

如果服务关闭，可在工作区根目录重新启动：

```bash
python3 -m http.server 8766
```

## 已实现

- 顶部导航：发现、收藏、设计
- 发现页颜色模式：样本按色相环组成碎片地图
- 发现页内容模式：样本按六类文化母题重组
- 底部分类入口：叙事与文化母体类、自然生物类、几何与构成类、材质与表现技法类、符号与文化抽象类、空间与布局类
- 底部年份时间轴：1780 到 2000
- 时间轴拖拽：控制当前出现在地图上的样本数量
- 地图拖拽、滚轮缩放、样本点击
- 右侧个人收藏格
- 样本展示页：样本图、年份、页码、分类说明、爱心收藏、底部更多样本和左右切换按钮

## 数据说明

当前是小样，使用本地 77 张福文化/纹样图作为素材，并自动扩展为 882 个可交互碎片。正式版可以继续接入更完整的真实样本库、来源档案、图像元数据和更精细的语义布局坐标。
