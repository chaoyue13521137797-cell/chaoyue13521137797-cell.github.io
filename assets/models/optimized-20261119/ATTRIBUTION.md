# Optimized runtime models — 2026-11-19

These files retain the source model licences and attribution listed in ../ATTRIBUTION.md. Original assets remain in their original directories.

- OBJ models (mug, socks, dress) were converted using Three.js OBJLoader geometry, preserving triangle positions, original UV coordinates, object names and paint material names.
- Socks and dress originally contain no vertex normals. Their per-face normals are generated by the site after decoding, matching the original OBJ loading process.
- Meshopt lossless buffer compression is required. The site bundles MeshoptDecoder; these GLB files do not need separate .bin or image requests.
- Textures already replaced in full by the application's selected pattern material were removed from the runtime copies. Original unused textures remain with the source assets.
- The vintage day bed retains its original materials and texture roles; texture images are limited to 512px with high quality JPEG encoding, including 4:4:4 normal maps.
- Only the silk pouf and cloth models were simplified, with meshoptimizer error 0.001 and locked borders. Pouf triangles: 81,280 to 26,538; cloth triangles: 115,200 to 11,846. Node names, materials, UV seams and retained vertex attributes are preserved.
- Mug handle remains a separate white material; Phong material was translated to the glTF PBR material model.

Original runtime resource total: 12,734,485 bytes / 26 requests. Optimized runtime resource total: 1,588,380 bytes / 8 requests. Measurements are before HTTP compression and exclude the shared 3D engine.
